NETWORK AUDIO INPUT

Radio & live stream deck

Load an authorized HTTPS radio / Icecast / Shoutcast stream into either deck and mix it with local tracks. Live streams may not support seeking, waveform analysis, beat grids, or scratching.

WAITING FOR A STREAM URL

A stream must allow browser cross-origin audio access (CORS) for the DJ mixer to process it. HTTPS is required on this HTTPS-hosted studio. We never bypass station authentication or stream licensing.

HARDWARE SETUP

Universal MIDI learn

Connect a standard MIDI controller, choose a software control, then move a physical knob / fader or press a pad to map it. Device-specific HID features still require testing.

NO CONTROLLER CONNECTED
Standard MIDI mapping is broad, not a promise that every proprietary controller function is compatible. Browser MIDI is not available on every mobile browser.

Notes and issues

Known limits: the current jog wheel seeks and nudges playback; true reverse-audio vinyl scratching is not implemented yet. MIDI support is basic and browser-dependent. Headphone cue routing and universal controller compatibility still need real hardware work. This preview is for testing, not paid gigs.
